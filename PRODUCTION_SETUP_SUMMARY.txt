⚠️  IMPORTANT REMINDERS
═══════════════════════════════════════════════════════════════════

1. SECRETS MANAGEMENT
   • JWT_SECRET must be 32+ characters
   • Store in environment variables, NEVER in code
   • Use secrets management (Render, Railway, AWS Secrets Manager)
   • Change defaults before production deployment

2. CORS CONFIGURATION
   • MUST specify exact domain
   • NO wildcards allowed
   • Communication between services uses internal DNS
   • Frontend must set API URL correctly

3. DATABASE OPERATIONS
   • Always backup before major operations
   • Test migrations in staging first
   • Keep database credentials secure
   • Enable SSL for remote connections

4. MONITORING
   • Set up log aggregation (CloudWatch, DataDog)
   • Enable error tracking (Sentry)
   • Configure alerts for critical errors
   • Monitor database performance

5. SECURITY
   • Review Helmet security headers
   • Test CORS restrictions
   • Verify rate limiting works
   • Validate SSL certificate
